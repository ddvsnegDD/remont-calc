# РПКМ — Калькулятор стоимости ремонта

Сайт-калькулятор стоимости ремонта квартир в Москве с двумя независимыми воронками.

> Демо-проект, выполненный в рамках курса «Разработчик чат-ботов под ключ» (Зерокодер).

## Что это

Веб-приложение из двух воронок:

- **B2C** (`b2c.html`) — для собственников. Квиз из 9 вопросов → расчёт цены с разбивкой → запись на бесплатный замер.
- **B2B** (`b2b-*.html`) — для дизайнеров и техзаказчиков. Регистрация → личный кабинет → расширенный квиз из 12 параметров → PDF-смета.

## Структура

```
remont-calc/
├── index.html          # Лендинг + переключатель воронок
├── b2c.html            # B2C-квиз
├── b2c-result.html     # Результат B2C: вилка цены + разбивка + запись на замер
├── b2b-login.html      # Логин/регистрация для профи
├── b2b-cabinet.html    # Личный кабинет с историей расчётов
├── b2b-quiz.html       # Расширенный квиз 12 параметров
├── b2b-result.html     # Результат B2B + кнопка скачивания PDF
├── css/
│   └── main.css
└── js/
    ├── calculator.js   # Движок расчёта (формулы, коэффициенты)
    ├── b2c.js          # Логика B2C-квиза
    ├── b2b.js          # Логика B2B-квиза
    ├── auth.js         # Авторизация (mock, в localStorage)
    └── pdf-export.js   # Генерация PDF-сметы (jsPDF + Cyrillic font)
```

## Технологии

Чистый HTML/CSS/JavaScript без сборки и фреймворков. Подключённые внешние библиотеки:
- **jsPDF** для генерации PDF
- **Google Fonts** — Inter, Manrope

## Калькулятор: как работает математика

База — средняя цена за м² по 6 категориям ремонта, откалибрована по аналитическому отчёту **«Рынок услуг по ремонту квартир в Москве» (Q1 2026)**:

| Категория | Цена «под ключ», ₽/м² | Сегмент рынка |
|-----------|-----------------------|---------------|
| Косметический | 20 000 – 30 000 | Хоумстейджинг, эконом low |
| Капитальный | 35 000 – 55 000 | Эконом / комфорт-low |
| Евроремонт | 60 000 – 85 000 | Комфорт / комфорт+ |
| Евроремонт+ | 100 000 – 150 000 | Бизнес-класс |
| Премиум | 160 000 – 220 000 | Бизнес-премиум |
| Люкс | 220 000 – 350 000 | Премиум-элит |

> 💡 В 2025 году стоимость работ выросла на 20–25%; маркировка цемента добавила 5–10%; логистика из Китая +40%. Психологический барьер 100k/м² для бизнес-класса в Москве уже преодолён.

Множители к базовой цене:
- **Тип дома** — 0.96–1.18 (новостройка-панель экономнее, сталинка дороже)
- **Отделка от застройщика** (только новостройка) — **0.48 для WhiteBox** (экономия ~52%, т.к. застройщик уже сделал стяжку, штукатурку, разводку, перегородки и сантехфаянс)
- **Перепланировка** — 1.00–1.12
- **Замена коммуникаций** — 1.00–1.16
- **Дизайн-проект** — 1.00–1.07
- **Сроки** — 1.00–1.07 (срочность дороже)

Для B2B дополнительно:
- **Этажность** (логистика) — 1.00–1.12
- **Отделка стен/потолков/полов** — 1.00–1.55 (натуральный камень дороже)
- **Инженерные системы** — 1.00–1.45 (smart home, спец. системы)
- **Количество санузлов и комнат** — мокрые зоны и сложность
- **Авторский надзор** — 1.00–1.08

Разбивка стоимости на работы / черновые / чистовые рассчитывается по доле от итога (для премиум доля чистовых выше).

## Хранение данных

Это статический сайт без бэкенда — всё хранится в `localStorage` пользователя:
- Заявки B2C: `rpkm-b2c-leads`
- Зарегистрированные B2B-пользователи: `rpkm-b2b-users`
- Сессия: `rpkm-b2b-session`
- Расчёты B2B: `rpkm-b2b-calcs`

## Что НЕ реализовано (для реальной версии нужен бэкенд)

- Реальная отправка лидов в Битрикс24
- Реальная модерация регистрации
- Серия догревающих сообщений
- Безопасное хранение паролей (сейчас в plain text — это **mock**, использовать только в демо)
- Telegram-нотификации менеджеру
- Аналитика воронок
- Email/SMS-уведомления
