# РПКМ — Калькулятор стоимости ремонта

## Резюме проекта для продолжения работы

### Что это
Калькулятор стоимости ремонта для компании РПКМ. Сделан в рамках курса «Зерокодер». Включает B2C-воронку (для собственников квартир), B2B-воронку (для дизайнеров/подрядчиков), **B2B-калькулятор офисного fit-out** (предварительный и детальный с 3000+ позициями), подписочный клуб с оплатой через ЮMoney, авторизацию по email-коду, интерактивные чек-листы приёмки работ с фотофиксацией и генерацией PDF-отчётов, и админ-панель. Данные заявок отправляются в Битрикс24 CRM, пользователи и подписки хранятся в PostgreSQL.

### Продакшн
- **URL:** https://remont-calc-production.up.railway.app
- **Хостинг:** Railway (auto-deploy из GitHub при push в main)
- **БД:** PostgreSQL на Railway (US West)
- **Email:** Brevo (ex-Sendinblue) HTTP API — транзакционные письма (коды авторизации, уведомления админу)
- **Платежи:** ЮMoney (кошелёк, P2P — для MVP)
- **CRM:** Битрикс24 (`crm.contact.add` + `crm.deal.add` через серверный прокси)
- **Репозиторий:** GitHub (`ddvsnegDD/remont-calc`), remote `neworigin`
- **Админка:** `/admin` (защищена паролем `ADMIN_PASSWORD`)

### Технический стек
- **React 18.3** + **Vite 5.4** (SPA)

### Система авторизации

**Архитектура:** Passwordless auth (email + одноразовый 4-значный код)

**Поток (единая точка входа):**
```
Header «Вход» → /login (LoginChoicePage)
  ├── B2C: email → POST /api/auth/send-code → код в email (Brevo) → verify → JWT cookie
  └── B2B: → /b2b-login (login-first или регистрация с полями ФИО, телефон, организация, специализация)
```

**Компоненты:**
- **LoginChoicePage** (`src/pages/LoginChoicePage.jsx`) — выбор B2C/B2B, B2C inline-авторизация
- **B2BLoginPage** (`src/pages/B2BLoginPage.jsx`) — login-first: вход → email+код, регистрация → полная форма
- **LoginModal** (`src/components/LoginModal.jsx`) — модальное окно для вызова из других страниц
  - Чекбокс согласия с Политикой конфиденциальности и Офертой (обязателен)
  - Таймер повторной отправки кода (60 сек)
- **AuthProvider** (`src/lib/auth.jsx`) — React-контекст авторизации
  - `user` — текущий пользователь (id, email, name, phone, role, organization)
  - `subscription` — текущая подписка (plan, status, expiresAt)
  - `hasAccess` — есть ли доступ (trial или active подписка)
  - `sendCode(email)` — с автоматическим retry (1 повтор через 1.5 сек при 500/network error)
  - `verify(email, code, ...)`, `logout()`, `refreshSubscription()`
- **Header** (`src/components/Layout.jsx`) — показывает имя/email (клик → кабинет) + «Выйти» или «Вход»
  - Клик по имени: B2C → `/club`, B2B → `/b2b-cabinet`

**Серверная часть:**
- JWT в httpOnly cookie `rpkm_token` (30 дней, secure в production)
- `authMiddleware` — проверяет JWT, ставит `req.user`
- `requireDB` — middleware, возвращает 503 если БД не подключена
- `GET /api/health` — диагностика: server, db, dbLive (реальный ping), email provider

### Система подписок

**Тарифы:**
| План | Цена | Срок |
|------|------|------|
| Триал | Бесплатно | 14 дней (один раз, только B2C, только по кнопке) |
| Месячный | 490 ₽ | 30 дней |
| Годовой | 4 900 ₽ | 365 дней |

**Важно:** Триал НЕ активируется автоматически при регистрации. Только по нажатию кнопки «Попробовать 14 дней бесплатно» → `POST /api/subscription/trial`.

**Поток оплаты:**
```
ClubPage → «Оплатить» → POST /api/subscription/pay → redirect ЮMoney quickpay
→ оплата → redirect ?payment=success&label=xxx → POST /api/subscription/activate
→ (параллельно) ЮMoney webhook → POST /api/subscription/yoomoney-webhook → активация
```

**Отмена подписки:**
```
ClubPage → «Отменить подписку» → confirm → POST /api/subscription/cancel
→ статус = cancelled, expires_at = NOW() → email на ddv1121@yandex.ru
```

**Gate (закрытый контент):**
- `B2CDetailPage` — детальная смета доступна только с подпиской (`hasAccess`)
- `ClubPage` — контент клуба (чек-листы, консультация, смета) виден при `hasAccess`
- `ChecklistsPage` / `ChecklistDetailPage` — требуют авторизацию

**Консультации:** 3 штуки в месяц, трекинг через localStorage (ключ: `rpkm_consult_${userId}_${year}_${month}`)

**БД-таблицы (server/db.js):**
- `users` — id, email, name, phone, role (b2c/b2b), organization, position, created_at
- `auth_codes` — email, code, expires_at, used
- `subscriptions` — user_id, plan, status (trial/active/pending/cancelled), expires_at, payment_label, amount

### Email-рассылка

**Провайдер:** Brevo (ex-Sendinblue) — приоритет, Resend — фолбэк

**Архитектура (`server/email.js`):**
- Выбор провайдера по наличию env-переменной (`BREVO_API_KEY` → Brevo, иначе `RESEND_API_KEY` → Resend)
- Если ни один ключ не задан — код только в логах сервера
- Отправка неблокирующая (fire-and-forget): `sendAuthCode(email, code).catch(...)`
- `sendRawEmail(to, subject, html)` — для уведомлений админу (отмена подписки и т.д.)

**Brevo:**
- HTTP API: `POST https://api.brevo.com/v3/smtp/email`
- Бесплатно 300 писем/день, любые получатели
- Отправитель: `delislenaqvi858@gmail.com` (верифицирован в Brevo)

### Админ-панель

**URL:** `/admin` (не отображается в навигации — доступ по прямой ссылке)

**Защита:** пароль через `x-admin-token` header, хранится в `sessionStorage`

**Что показывает:**
- **Карточки статистики:** всего пользователей, B2B профи, активных триалов, платных подписок, ожидающих оплаты
- **Таблица B2C:** ID, email, имя, телефон, подписка (статус-бейдж), дата окончания, регистрация, кнопка удаления
- **Таблица B2B:** ID, email, имя, телефон, организация, специализация, регистрация, кнопка удаления

**Удаление пользователя:** кнопка корзины → подтверждение → `DELETE /api/admin/users/:id` → удаляет подписки, коды, пользователя

**API:**
- `GET /api/admin/stats` — агрегированная статистика
- `GET /api/admin/users` — список пользователей с подписками (JOIN)
- `DELETE /api/admin/users/:id` — удаление пользователя со всеми данными

**1. `calculateB2C()` из `calculator.js`** — быстрый расчёт
- Вход: ответы квиза (площадь, тип ремонта, модификаторы)
- Выход: диапазон цен (low–high), tierLabel, days, modifiers
- Используется: виджет на главной, квиз в режиме «Быстрый расчёт», кнопка «Получить расчёт» на B2CBookPage

**2. `SpecCalc.compute()` из `spec-calculator.js`** — детальная смета
- Вход: `{ area, rooms, sanitary, windows, mode, tier, replan }`
  - `mode`: `'whitebox'` | `'full'`
  - `tier`: `'capital'` | `'euro'` | `'premium'`
  - `replan`: `'no'` | `'light'` | `'full'`
  - `windows`: 0–20 (при 0 оконные позиции исключаются из сметы)
- Выход: `{ mode, tier, tierLabel, inputs, lines[], groups[], totals: {grand, works, materials, worksPct, matPct}, perM2 }`
- Генерирует ~50 позиций с работами, материалами, объёмами, ценами
- Данные из реальных Excel-смет подрядчика (привязка к Q1 2026 Москва)

**4. `OfficeCalc.compute()` из `office-calculator.js`** — предварительный офисный fit-out
- Вход: `{ tier, area, meetingRooms, workplaces, serverRoom, urgency, designProject, excludeOptional, includeOptional }`
  - `tier`: `'standard'` | `'business'` | `'premium'`
  - `urgency`: `'standard'` | `'fast'` (+7%)
  - `designProject`: `'need'` | `'have'` (исключает раздел дизайна)
- Выход: `{ sections[], modifiers[], totals: {grand, perM2Grand}, meta: {baselineMR, extraMR}, scaleApplied }`
- **3 фазы расчёта:**
  1. Базовые ставки: `OFFICE_BUDGET_RAW[tier]` × `OFFICE_INFLATION_2026` (1.11) × площадь
  2. Масштабные коэффициенты для больших офисов (5 000–50 000 м²):
     - Зона 1: ≤5 000 м² → mult = 1.0 (без изменений)
     - Зона 2: 5 000–10 000 м² → линейная интерполяция
     - Зона 3: ≥10 000 м² → степенная формула `(refArea / area)^alpha`
     - Отделка: alpha=0.06, refArea=5000 (объёмная скидка)
     - Инженерия: alpha=0.20, откалибровано по реальным объектам (Стандарт: Технопарк 19 226 м², Бизнес: 43 672 м², Премиум: экстраполяция ×0.60)
  3. Модификаторы: доп. переговорные, серверная (+200K), срочность (+7%)
- Данные: 25+ статей по 6 секциям (управление, дизайн, общестрой, мебель, электрика, механика)
- Ставки откалиброваны на июнь 2026 из реальных инженерных протоколов и смет

**5. Детальный офисный калькулятор** (`B2BOfficeDetailPage.jsx`)
- **Переключатель категории:** Стандарт / Бизнес (разные файлы данных)
- **Два таба:**
  - Отделка (МИН/МАКС):
    - Стандарт — `office-finish-data.js`: 5 разделов (S1–S5), 14 групп, ~2200 позиций
    - Бизнес — `office-finish-data-business.js`: 5 разделов (S1–S5), 36 групп, 534 позиции, из Excel МАКС/МИН
  - Инженерия ВИС:
    - Стандарт — `office-vis-data.js`: 4 раздела (механика/ЭОМ × надзем/подзем), ~1700 позиций
    - Бизнес — `office-vis-data-business.js`: 3 раздела (механика + электрика + слаботочка), 2074 позиции, из 3 Excel-файлов
- **Параметры:** S1 (надземная площадь), S2 (подземная), S3 (КПП надзем), S4 (КПП подзем), S5 (лестничные клетки)
- **Формула отделки:** объём = площадь × k × 1.10 × areaMult, стоимость = объём × (pw + pm)
- **Формула ВИС (обе категории):** единая формульная система из Excel (Q–Z колонки):
  - `rtype=Площадь`: vol = ceil(qOrig × area / refArea)
  - `rtype=Шт`: vol = max(min, ceil(qOrig × area / refArea / krat) × krat)
  - `rtype=Фикс`: vol = ceil(qOrig), `rtype=Расценки`: масштабируются цены, не объёмы
  - Ref-площади: Стандарт S1=19 226 м², S2=3 528 м²; Бизнес: 43 672 м²
- **Бизнес-масштаб:** areaMult = `(50000 / площадь)^alpha` (отделка α=0.08, инженерия α=0.12) — малые площади → выше цена/м²
- **Бизнес k-коэффициенты:** включают +15% к исходным объёмам (калибровка на бизнес-класс)
- **Наценки:** Управление проектом (15%) + Дизайн (5%) = +20% к подитогу каждого таба
- **Lazy-loading:** данные загружаются через динамические `import()` с кешированием на уровне модуля; начальный чанк страницы 23 КБ (вместо 901 КБ), данные подгружаются при выборе категории

### Интеграция с Битрикс24 CRM

**Архитектура:** Фронтенд → `POST /api/lead` (Express-прокси) → Битрикс24 REST API

**Серверный прокси (`server.js`):**
- Принимает `{ title, name, phone, email, comment, source }` от фронтенда
- Создаёт контакт через `crm.contact.add` (имя, телефон, email)
- Создаёт сделку через `crm.deal.add` (привязана к контакту, с комментарием-расчётом)
- Вебхук в переменной окружения `B24_WEBHOOK` (не в коде!)

**Фронтенд (`src/lib/bitrix.js`):**
- `createLead()` — отправляет заявку на `/api/lead`
- `formatQuickComment()` — форматирует быстрый расчёт для поля COMMENTS сделки
- `formatDetailComment()` — форматирует детальную смету для поля COMMENTS сделки
- Вызывается из: B2CQuizPage (оба режима), B2CDetailPage, B2CBookPage

**Формы, отправляющие лиды:**
| Страница | Тип лида | Пример title сделки |
|----------|----------|---------------------|
| B2CQuizPage (быстрый) | Быстрый расчёт | `B2C · Быстрый расчёт · 60 м² · Капитальный стандарт` |
| B2CQuizPage (детальный) | Квиз-смета | `B2C · Квиз-смета · 60 м² · 1 234 567 ₽` |
| B2CDetailPage | Детальная смета | `B2C · Детальная смета · 60 м² · 1 234 567 ₽` |
| B2CBookPage | Запись на замер | `B2C · Запись на замер · ЖК Нева` |

**Вход:**
```

**Быстрый расчёт:**

```

### Как запустить

**Разработка (два терминала):**
```bash
cd remont-calc
npm install
npm run dev          # → http://localhost:5173 (Vite dev server)
npm run dev:server   # → http://localhost:3001 (Express API, нужен DATABASE_URL)
```
Vite проксирует `/api` → `localhost:3001` автоматически.

**Продакшн (локально):**
```bash
npm run build      # → dist/
npm start          # → Express сервер на :3000 (нужны env-переменные)
```

**Деплой:** push в main → Railway автоматически собирает и деплоит
