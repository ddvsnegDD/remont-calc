# ТЗ: текст на странице /payment/return после выхода из оплаты

## Проблема

Если на странице ЮKassa нажать «Выйти из оплаты» (или закрыть её) и вернуться на сайт, /payment/return минуту опрашивает сервер и показывает состояние timeout: «Платёж обрабатывается. Доступ откроется автоматически…». Платёж при этом не оплачен и в статусе pending. Человек ждёт доступ, которого не будет.

Найдено в боевой проверке 01.10 (платежи 8 и 9). ЮKassa держит такой платёж открытым неопределённо долго, поэтому статус canceled к моменту возврата обычно не приходит и состояние canceled здесь не сработает.

## Что сделать

Файл: src/pages/PaymentReturnPage.jsx, блок `state === 'timeout'` (строки 107-115).

1. Заголовок: «Оплата пока не подтверждена».
2. Текст (один абзац, без обещаний, которые зависят от платежа):
   «Если вы уже заплатили, доступ откроется сам в течение нескольких минут, обновите страницу. Если вы вышли из оплаты, деньги не списаны, можно начать заново. Если оплатили, а доступа нет, напишите на ddv1121@yandex.ru.»
   Почту оставить ссылкой mailto с тем же стилем, что сейчас.
3. Под текстом две кнопки: «Обновить страницу» (window.location.reload()) и «К тарифам» (navigate(retryTo), уже есть: /pro для PRO, /club для Клуба). «К тарифам» с variant="terra" (как у остальных состояний), «Обновить страницу» с variant="outline" (он есть в src/components/Btn.jsx).
4. Текст состояния canceled («Оплата не прошла или отменена», «Деньги не списаны») не менять.

## Что не трогать

- Логику опроса (интервал 2 с, таймаут 60 с), состояния pending, succeeded, canceled, invalid.
- server.js, server/db.js, server/yookassa.js: сервер не меняется.
- Тексты оферты, политики, согласия.

## Критерии приёмки

1. Файл PaymentReturnPage.jsx меняется только в блоке timeout, других изменений нет.
2. Во фразах нет слов «Доступ откроется автоматически» без условия «если вы уже заплатили».
3. Кнопка «К тарифам» ведёт на /pro для платежа PRO и на /club для платежа Клуба.
4. `npx vite build` проходит без ошибок.
5. Один коммит, без push. После него остановиться и написать отчёт docs/REPORT_return_text.md (короткий: что изменено, какой хеш).

## Боевая проверка (после деплоя, по команде Дмитрия)

1. Аккаунт 58 открывает /club, выбирает месяц, на странице ЮKassa нажимает «Выйти из оплаты», возвращается на сайт.
2. Через минуту видит «Оплата пока не подтверждена» и две кнопки.
3. «К тарифам» открывает /club.
