# РПКМ — Калькулятор стоимости ремонта

## Резюме проекта для продолжения работы

### Что это
Демо-проект калькулятора стоимости ремонта для компании РПКМ. Сделан в рамках курса «Зерокодер». Включает B2C-воронку (для собственников квартир), B2B-воронку (для дизайнеров/подрядчиков), подписочный клуб с оплатой через ЮMoney, авторизацию по email-коду и админ-панель. Данные заявок отправляются в Битрикс24 CRM, пользователи и подписки хранятся в PostgreSQL.

### Продакшн
- **URL:** https://remont-calc-production.up.railway.app
- **Хостинг:** Railway (auto-deploy из GitHub при push в main)
- **БД:** PostgreSQL на Railway (US West)
- **Email:** Brevo (ex-Sendinblue) HTTP API — транзакционные письма (коды авторизации)
- **Платежи:** ЮMoney (кошелёк, P2P — для MVP)
- **CRM:** Битрикс24 (`crm.contact.add` + `crm.deal.add` через серверный прокси)
- **Репозиторий:** GitHub (`ddvsnegDD/remont-calc`), remote `neworigin`
- **Админка:** `/admin` (защищена паролем `ADMIN_PASSWORD`)

### Технический стек
- **React 18.3** + **Vite 5.4** (SPA)

- **JWT** (jsonwebtoken) — сессии в httpOnly cookie (30 дней)

### Система авторизации

**Архитектура:** Passwordless auth (email + одноразовый 4-значный код)

**Поток:**
```
LoginModal → email → POST /api/auth/send-code → код в email (Brevo) 
          → ввод кода → POST /api/auth/verify → JWT cookie → авторизован
```

**Компоненты:**
- **LoginModal** (`src/components/LoginModal.jsx`) — модальное окно, 3 шага (email → код → успех)
  - Чекбокс согласия с Политикой конфиденциальности и Офертой (обязателен)
  - Таймер повторной отправки кода (60 сек)
  - Авто-фокус на поле кода
- **AuthProvider** (`src/lib/auth.jsx`) — React-контекст авторизации
  - `user` — текущий пользователь (id, email, name)
  - `subscription` — текущая подписка (plan, status, expiresAt)
  - `hasAccess` — есть ли доступ (trial или active подписка)
  - `sendCode(email)`, `verify(email, code)`, `logout()`, `refreshSubscription()`
- **Header** (`src/components/Layout.jsx`) — показывает имя/email + кнопку «Выйти» или «Войти»

**Серверная часть:**
- JWT в httpOnly cookie `rpkm_token` (30 дней, secure в production)
- `authMiddleware` — проверяет JWT, ставит `req.user`
- `requireDB` — middleware, возвращает 503 если БД не подключена

### Система подписок

**Тарифы:**
| План | Цена | Срок |
|------|------|------|
| Триал | Бесплатно | 14 дней (один раз) |
| Месячный | 490 ₽ | 30 дней |
| Годовой | 4 900 ₽ | 365 дней |

**Поток оплаты:**
```
ClubPage → «Оплатить» → POST /api/subscription/pay → redirect ЮMoney quickpay
→ оплата → redirect ?payment=success&label=xxx → POST /api/subscription/activate
→ (параллельно) ЮMoney webhook → POST /api/subscription/yoomoney-webhook → активация
```

**Gate (закрытый контент):**
- `B2CDetailPage` — детальная смета доступна только с подпиской (`hasAccess`)
- `ClubPage` — контент клуба (чек-листы, консультация, смета) виден при `hasAccess`

**БД-таблицы (server/db.js):**
- `users` — id, email, name, phone, created_at
- `auth_codes` — email, code, expires_at, used
- `subscriptions` — user_id, plan, status (trial/active/pending), expires_at, payment_label, amount

### Email-рассылка

**Провайдер:** Brevo (ex-Sendinblue) — приоритет, Resend — фолбэк

**Архитектура (`server/email.js`):**
- Выбор провайдера по наличию env-переменной (`BREVO_API_KEY` → Brevo, иначе `RESEND_API_KEY` → Resend)
- Если ни один ключ не задан — код только в логах сервера
- Отправка неблокирующая (fire-and-forget): `sendAuthCode(email, code).catch(...)`

**Brevo:**
- HTTP API: `POST https://api.brevo.com/v3/smtp/email`
- Бесплатно 300 писем/день, любые получатели
- Отправитель: `delislenaqvi858@gmail.com` (верифицирован в Brevo)

### Ключевые расчётные движки

**1. `calculateB2C()` из `calculator.js`** — быстрый расчёт
- Вход: ответы квиза (площадь, тип ремонта, модификаторы)
- Выход: диапазон цен (low–high), tierLabel, days, modifiers
- Используется: виджет на главной, квиз в режиме «Быстрый расчёт», кнопка «Получить расчёт» на B2CBookPage

**2. `SpecCalc.compute()` из `spec-calculator.js`** — детальная смета
- Вход: `{ area, rooms, sanitary, windows, mode, tier, replan }`
  - `mode`: `'whitebox'` | `'full'`
  - `tier`: `'capital'` | `'euro'` | `'premium'`
  - `replan`: `'no'` | `'light'` | `'full'`
  - `windows`: 0–20 (при 0 оконные позиции исключаются из сметы)
- Выход: `{ mode, tier, tierLabel, inputs, lines[], groups[], totals: {grand, works, materials, worksPct, matPct}, perM2 }`
- Генерирует ~50 позиций с работами, материалами, объёмами, ценами
- Данные из реальных Excel-смет подрядчика (привязка к Q1 2026 Москва)
- Используется: квиз в режиме «Детальная смета», B2CDetailPage

**3. Маппинг квиз → SpecCalc** (в B2CQuizPage):
```javascript
const tierMap = { cosmetic: 'capital', capital: 'capital', euro: 'euro', premium: 'premium' };
const quizTier = tierMap[answers.repair_type] || 'capital';
const quizMode = (quizTier === 'premium') ? 'full' : (answers.finish_type === 'whitebox' ? 'whitebox' : 'full');
const quizRooms = area < 35 ? 1 : area < 55 ? 2 : area < 80 ? 3 : area < 120 ? 4 : 5;
const quizSanitary = area < 60 ? 1 : area < 120 ? 2 : 3;
const quizWindows = area < 35 ? 2 : area < 55 ? 3 : area < 80 ? 4 : area < 120 ? 6 : 8;
```

### Интеграция с Битрикс24 CRM

**Архитектура:** Фронтенд → `POST /api/lead` (Express-прокси) → Битрикс24 REST API

**Серверный прокси (`server.js`):**
- Принимает `{ title, name, phone, email, comment, source }` от фронтенда
- Создаёт контакт через `crm.contact.add` (имя, телефон, email)
- Создаёт сделку через `crm.deal.add` (привязана к контакту, с комментарием-расчётом)
- Вебхук в переменной окружения `B24_WEBHOOK` (не в коде!)

**Фронтенд (`src/lib/bitrix.js`):**
- `createLead()` — отправляет заявку на `/api/lead`
- `formatQuickComment()` — форматирует быстрый расчёт для поля COMMENTS сделки
- `formatDetailComment()` — форматирует детальную смету для поля COMMENTS сделки
- Вызывается из: B2CQuizPage (оба режима), B2CDetailPage, B2CBookPage

**Формы, отправляющие лиды:**
| Страница | Тип лида | Пример title сделки |
|----------|----------|---------------------|
| B2CQuizPage (быстрый) | Быстрый расчёт | `B2C · Быстрый расчёт · 60 м² · Капитальный стандарт` |
| B2CQuizPage (детальный) | Квиз-смета | `B2C · Квиз-смета · 60 м² · 1 234 567 ₽` |
| B2CDetailPage | Детальная смета | `B2C · Детальная смета · 60 м² · 1 234 567 ₽` |
| B2CBookPage | Запись на замер | `B2C · Запись на замер · ЖК Нева` |

### Как запустить

```bash
cd remont-calc
npm install
npm run dev          # → http://localhost:5173 (Vite dev server)
npm run dev:server   # → http://localhost:3001 (Express API, нужен DATABASE_URL)
```

**Продакшн (локально):**
```bash
npm run build      # → dist/
```
