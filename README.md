# РПКМ — Калькулятор стоимости ремонта

Веб-приложение для расчёта стоимости ремонта квартир и офисов в Москве.

> Демо-проект, выполненный в рамках курса «Зерокодер».

## Стек

- React 18.3 + Vite 5.4
- React Router DOM 6 (SPA, 18 маршрутов)
- Lucide React (иконки)
- Без бэкенда — все данные в sessionStorage

## Функционал

- **B2C-воронка** — квиз для собственников → детальная смета ~50 позиций
- **B2B-воронка** — кабинет подрядчика, офисный fit-out
- **Калькулятор** — привязка к ценам Q1 2026, Москва
- **Партнёрская программа** — B2B и B2C реферальные ссылки
- **Клуб владельцев** — подписка с калькулятором выгоды
- **Дашборд** — аналитика с SVG-графиками

## Запуск

```bash
npm install
npm run dev      # → http://localhost:3000
```

## Сборка и production

```bash
npm run build    # → dist/
npm start        # serve dist на PORT (по умолчанию 3000)
```
