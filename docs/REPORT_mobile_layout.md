# Отчёт: мобильная вёрстка — страницы шире экрана телефона

**ТЗ:** `docs/TASK_mobile_layout.md`, части 1–2.
**Дата выполнения:** 2026-09-26.
**Коммиты:** `0fa8ee4` (часть 1), `dbfaa9f` (часть 2).
**Деплой:** не выполнялся, push не делался.

## Среда проверки

Нет `.env`, нет локального PostgreSQL. Дев-сервер (`npm run dev`, порт 3000) поднимался без бэкенда — `/api/auth/me` и подобные отвечают `500`, страницы, требующие входа, показывают свою ветку «Авторизуйтесь для доступа» или пейволл. Проверка велась в браузерной панели (эмуляция viewport 390×844, 360×800, 1280×900) через `document.documentElement.scrollWidth`, `getComputedStyle(...).gridTemplateColumns` и скриншоты.

Для мест, недоступных без входа, использованы два приёма:
1. **Живая форсированная проверка на смонтированном элементе** — временно (через рантайм, не в файлах) выставлялось старое значение `grid-template-columns` инлайн-стилем на уже отрисованном элементе доступной страницы, замерялся `scrollWidth`, затем откатывалось — так получены честные числа «было/стало» без правки исходников.
2. **Изолированная HTML-репродукция** (по образцу части 1) — для трёх страниц, полностью закрытых платным гейтом (`B2CDetailPage.jsx`, `B2BOfficePage.jsx`, `B2BOfficeDetailPage.jsx`), не открыть которые без БД в принципе: разметка и классы из исходников скопированы в статический HTML с реальным собранным `global.css` (`npx vite build` → `dist/assets/*.css`), отдано локальным `http.server`, замерено на 390/360/1280px.

Подтверждено скриншотом на 360px: карточка идёт сразу под текстовым блоком, на всю ширину, за край не уходит.

## Критерий 4. Поля «Адрес», «Помещение», дата в чек-листе

Реальная страница (`/checklists/floor`) без входа недоступна — поля не рендерятся. Механизм (`input[type=date]` без `min-width:0` распирает грид-трек) проверен изолированной HTML-репродукцией точно той же разметки/стилей на статическом сервере (часть 1): без фикса `scrollWidth` контейнера — 366px при 360px экрана, с фиксом — 360px, ровно по границе. При 390px переполнения от этого элемента не было даже без фикса. Живьём, что дата действительно выбирается (не просто не распирает), не проверено — репродукция не интерактивна в части выбора даты браузерным date-picker'ом.

## Критерий 5. Компьютер (1280px) — без изменений

- `/` — подвал (4 колонки) и блок «Клуб» (2 колонки) — скриншоты, до/после визуально совпадают с рассчитанными по формуле пропорциями (напр. `.footer-grid`: 412.8px/206.4px/206.4px/206.4px — ровно `2fr 1fr 1fr 1fr` от доступной ширины).
- `/club`, `/login`, `/b2c` — доступны без входа, проверены живьём: `getComputedStyle(...).gridTemplateColumns` даёт равные колонки, соответствующие исходной раскладке (290px×2, 252px×2, 266px×2 соответственно), скриншот `/login` приложен.
- `B2CDetailPage.jsx`, `B2BOfficePage.jsx`, `B2BOfficeDetailPage.jsx` — недоступны без входа, проверены на 1280px той же изолированной репродукцией: все грид-контейнеры вернулись к исходному числу колонок (3 или 2), `document.documentElement.scrollWidth` = 1280.
