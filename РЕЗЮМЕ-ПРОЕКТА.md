# РПКМ — Калькулятор стоимости ремонта

## Резюме проекта для продолжения работы

### Что это
Демо-проект калькулятора стоимости ремонта для компании РПКМ. Сделан в рамках курса «Зерокодер». Включает B2C-воронку (для собственников квартир) и B2B-воронку (для дизайнеров/подрядчиков). Данные заявок отправляются в Битрикс24 CRM, локальное состояние — в sessionStorage/localStorage.

### Продакшн
- **URL:** https://remont-calc-production.up.railway.app
- **Хостинг:** Railway (auto-deploy из GitHub при push в main)
- **CRM:** Битрикс24 (`crm.contact.add` + `crm.deal.add` через серверный прокси)
- **Репозиторий:** GitHub (`ddvsnegDD/remont-calc`), remote `neworigin`

### Технический стек
- **React 18.3** + **Vite 5.4** (SPA)
- **Express 5** — сервер (статика + API-прокси для Битрикс24)
- **React Router DOM 6.26** — клиентская маршрутизация
- **Lucide React** — иконки
- Стили: единый `global.css` (~1800 строк) + inline styles через объект `C` из `theme.js`
- Шрифты: **Cormorant Garamond** (display serif), **Inter** (body), **Golos Text** (UI-заголовки)

### Дизайн-система
- **Основной цвет (Terra):** #B95C38 (тёплый терракот)
- **Тёмный (Graphite):** #1A1A1C
- **Фон (Off-white):** #F7F7F8
- **Серые:** #6B7280 (text), #E4E4E7 (borders), #F0F0F2 (backgrounds)
- **Скругления:** 14px (карточки), 24px (premium-карточки), 8px (кнопки/инпуты)
- **Glassmorphism:** `backdrop-filter: blur(32px)`, `rgba(255,255,255,0.78)` фон, multi-layer shadows
- **Тени:** `0 4px 16px rgba(30,58,95,0.08)` (стандарт), `0 12px 40px rgba(30,58,95,0.12)` (крупные)

### Ключевые расчётные движки

**1. `calculateB2C()` из `calculator.js`** — быстрый расчёт
- Вход: ответы квиза (площадь, тип ремонта, модификаторы)
- Выход: диапазон цен (low–high), tierLabel, days, modifiers
- Используется: виджет на главной, квиз в режиме «Быстрый расчёт», кнопка «Получить расчёт» на B2CBookPage

**2. `SpecCalc.compute()` из `spec-calculator.js`** — детальная смета
- Вход: `{ area, rooms, sanitary, windows, mode, tier, replan }`
  - `mode`: `'whitebox'` | `'full'`
  - `tier`: `'capital'` | `'euro'` | `'premium'`
  - `replan`: `'no'` | `'light'` | `'full'`
  - `windows`: 0–20 (при 0 оконные позиции исключаются из сметы)
- Выход: `{ mode, tier, tierLabel, inputs, lines[], groups[], totals: {grand, works, materials, worksPct, matPct}, perM2 }`
- Генерирует ~50 позиций с работами, материалами, объёмами, ценами
- Данные из реальных Excel-смет подрядчика (привязка к Q1 2026 Москва)
- Используется: квиз в режиме «Детальная смета», B2CDetailPage

**3. Маппинг квиз → SpecCalc** (в B2CQuizPage):
```javascript
const tierMap = { cosmetic: 'capital', capital: 'capital', euro: 'euro', premium: 'premium' };
const quizTier = tierMap[answers.repair_type] || 'capital';
const quizMode = (quizTier === 'premium') ? 'full' : (answers.finish_type === 'whitebox' ? 'whitebox' : 'full');
const quizRooms = area < 35 ? 1 : area < 55 ? 2 : area < 80 ? 3 : area < 120 ? 4 : 5;
const quizSanitary = area < 60 ? 1 : area < 120 ? 2 : 3;
const quizWindows = area < 35 ? 2 : area < 55 ? 3 : area < 80 ? 4 : area < 120 ? 6 : 8;
```

### Интеграция с Битрикс24 CRM

**Архитектура:** Фронтенд → `POST /api/lead` (Express-прокси) → Битрикс24 REST API

**Серверный прокси (`server.js`):**
- Принимает `{ title, name, phone, email, comment, source }` от фронтенда
- Создаёт контакт через `crm.contact.add` (имя, телефон, email)
- Создаёт сделку через `crm.deal.add` (привязана к контакту, с комментарием-расчётом)
- Вебхук в переменной окружения `B24_WEBHOOK` (не в коде!)

**Фронтенд (`src/lib/bitrix.js`):**
- `createLead()` — отправляет заявку на `/api/lead`
- `formatQuickComment()` — форматирует быстрый расчёт для поля COMMENTS сделки
- `formatDetailComment()` — форматирует детальную смету для поля COMMENTS сделки
- Вызывается из: B2CQuizPage (оба режима), B2CDetailPage, B2CBookPage

**Формы, отправляющие лиды:**
| Страница | Тип лида | Пример title сделки |
|----------|----------|---------------------|
| B2CQuizPage (быстрый) | Быстрый расчёт | `B2C · Быстрый расчёт · 60 м² · Капитальный стандарт` |
| B2CQuizPage (детальный) | Квиз-смета | `B2C · Квиз-смета · 60 м² · 1 234 567 ₽` |
| B2CDetailPage | Детальная смета | `B2C · Детальная смета · 60 м² · 1 234 567 ₽` |
| B2CBookPage | Запись на замер | `B2C · Запись на замер · ЖК Нева` |

### 152-ФЗ (персональные данные)

- **Политика конфиденциальности** (`/privacy`) — 9 разделов: собираемые данные, цели, правовое основание, хранение, третьи стороны, права субъекта, сроки, cookies, контакты
- **Согласие** — чекбокс со ссылкой на `/privacy` на всех формах (B2CQuizPage, B2CDetailPage, B2CBookPage)
- **Хранение** — Битрикс24 (серверы в РФ), sessionStorage (локально, временно)

### Потоки пользователя (B2C)

**Быстрый расчёт:**
```
Главная → «Быстрый расчёт» → Квиз (9 шагов) → calculateB2C() → /b2c-result (вилка цен)
```

**Быстрый расчёт → «Нет, но хочу дизайн-проект у вас» (шаг 7):**
```
Квиз → шаг 7 «Нет, но хочу сделать у вас» → /b2c-book (запись на замер) → «Получить расчёт» → calculateB2C() → /b2c-result
```

**Быстрый расчёт → «Да, есть готовый проект» (шаг 7):**
```
Квиз → шаг 7 «Да, готовый проект» → /b2c-detail?source=has-project (детальная форма) → SpecCalc → /b2c-result-detail
```

**Детальная смета (прямой вход):**
```
Главная → «Детальная смета» → /b2c-detail → SpecCalc → /b2c-result-detail
```

### Как запустить

**Разработка:**
```bash
cd remont-calc
npm install
npm run dev        # → http://localhost:3000 (Vite dev server)
```

**Продакшн (локально):**
```bash
npm run build      # → dist/
npm start          # → Express сервер на :3000 (нужен B24_WEBHOOK в env)
```

**Деплой:** push в main → Railway автоматически собирает и деплоит

### Сборка
```bash
npx vite build     # → dist/ (388 KB JS + 37 KB CSS gzipped: 111 KB + 7.5 KB)
```
