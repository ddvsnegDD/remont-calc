# РПКМ — Калькулятор стоимости ремонта

## Резюме проекта для продолжения работы

### Что это
Демо-проект калькулятора стоимости ремонта для компании РПКМ. Сделан в рамках курса «Зерокодер». Включает B2C-воронку (для собственников квартир) и B2B-воронку (для дизайнеров/подрядчиков). Без бэкенда — все данные в sessionStorage/localStorage.

### Технический стек
- **React 18.3** + **Vite 5.4** (SPA)
- **React Router DOM 6.26** — клиентская маршрутизация
- **Lucide React** — иконки
- Стили: единый `global.css` (~1800 строк) + inline styles через объект `C` из `theme.js`
- Шрифты: **Cormorant Garamond** (display serif), **Inter** (body), **Golos Text** (UI-заголовки)
- Без backend — все данные в sessionStorage/localStorage

### Дизайн-система
- **Основной цвет (Terra):** #B95C38 (тёплый терракот)
- **Тёмный (Graphite):** #1A1A1C
- **Фон (Off-white):** #F7F7F8
- **Серые:** #6B7280 (text), #E4E4E7 (borders), #F0F0F2 (backgrounds)
- **Скругления:** 14px (карточки), 24px (premium-карточки), 8px (кнопки/инпуты)
- **Glassmorphism:** `backdrop-filter: blur(32px)`, `rgba(255,255,255,0.78)` фон, multi-layer shadows
- **Тени:** `0 4px 16px rgba(30,58,95,0.08)` (стандарт), `0 12px 40px rgba(30,58,95,0.12)` (крупные)

### Ключевые расчётные движки

**1. `calculateB2C()` из `calculator.js`**
- Вход: площадь + тип дома
- Выход: диапазон цен (low–high) на основе базовых ставок за м²
- Используется только в виджете калькулятора на главной странице

**2. `SpecCalc.compute()` из `spec-calculator.js`** — основной движок
- Вход: `{ area, rooms, sanitary, windows, mode, tier, replan }`
  - `mode`: `'whitebox'` | `'full'`
  - `tier`: `'capital'` | `'euro'` | `'premium'`
  - `replan`: `'no'` | `'minor'` | `'major'`
- Выход: `{ mode, tier, tierLabel, inputs, lines[], groups[], totals: {grand, works, materials, worksPct, matPct}, perM2 }`
- Генерирует ~50 позиций с работами, материалами, объёмами, ценами
- Данные из реальных Excel-смет подрядчика (привязка к Q1 2026 Москва)
- Используется: B2CQuizPage, B2CBookPage, B2CDetailPage → все ведут на B2CResultDetailPage

**3. Маппинг квиз → SpecCalc** (одинаковый в B2CQuizPage и B2CBookPage):
```javascript
const tierMap = { cosmetic: 'capital', capital: 'capital', euro: 'euro', premium: 'premium' };
const quizTier = tierMap[answers.repair_type] || 'capital';
const quizMode = (quizTier === 'premium') ? 'full' : (answers.finish_type === 'whitebox' ? 'whitebox' : 'full');
const quizRooms = area < 35 ? 1 : area < 55 ? 2 : area < 80 ? 3 : area < 120 ? 4 : 5;
const quizSanitary = area < 60 ? 1 : area < 120 ? 2 : 3;
const quizWindows = area < 35 ? 2 : area < 55 ? 3 : area < 80 ? 4 : area < 120 ? 6 : 8;
```

### sessionStorage-ключи

### Главная страница (HomePage.jsx) — 7 секций

1. **HeroSection** — премиальный герой с фотографическим фоном интерьера (`hero-interior.jpg`), gradient overlay, blueprint-сетка, glassmorphism-калькулятор, превью-карточка, трастовая полоса внизу
2. **PricingSection** — 4 карточки категорий (Эконом/Комфорт/Бизнес/Премиум) с градиентными фонами
3. **BentoSection** — 3 карточки «Как мы работаем» (Расчёт, Замер, Договор)
4. **GuaranteesSection** — аккордеон гарантий + визуальная карточка
5. **ClubSection** — калькулятор выгоды подписки (range slider)
6. **ProSection** — тёмная секция для профессионалов (glass-cards, `dark-pro-bg.jpeg`)
7. **B2BPartnerHero** — тёмная секция партнёрской программы

### Как запустить
```bash
cd remont-calc
npm install
npm run dev        # → http://localhost:3000
```
Или через Claude Preview: `npx vite --port 3001`

### Сборка
```bash
npx vite build     # → dist/ (388 KB JS + 37 KB CSS gzipped: 111 KB + 7.5 KB)
```
